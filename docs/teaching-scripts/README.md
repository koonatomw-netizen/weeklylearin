## ก่อนสอนทุกสัปดาห์ (10 นาที)

1. เข้า Admin แล้วกด **Import Weeks 3 to 12** ใน Lesson Library (ทำครั้งเดียว) ระบบสร้างบทเรียนและแผนฉบับร่างให้ทุกสัปดาห์
2. เปิดแผนของสัปดาห์นั้นใน Weekly Planner ตรวจโจทย์และเกม แล้วกด **Publish**
3. เริ่มห้องจาก Live Sessions จด **รหัสห้อง** แล้วเปิดสไลด์แรกบนโปรเจกเตอร์
4. ลองเข้าห้องด้วยมือถือของคุณเอง 1 เครื่อง ตรวจว่าเห็นโจทย์และเกม
5. เตรียมเดโมของสัปดาห์ (ดูหัวข้อ "เตรียมก่อนสอน" ในสคริปต์) และเตรียมภาพหน้าจอสำรองไว้เสมอ
6. ถ้าจะใช้ปุ่ม **ฟีดแบ็กจาก AI** ต้องตั้ง `TOKENME_API_KEY` ไว้ที่เซิร์ฟเวอร์ ถ้าไม่ตั้ง ปุ่มจะบอกให้ใช้เช็กลิสต์ตัวเองแทน เกมยังเล่นได้ตามปกติ

## วิธีเดินห้อง (ใช้ซ้ำทุกสัปดาห์)

- **ลำดับสไลด์:** เปิดสัปดาห์ (หน้าแรก) → เช็กอิน → แนวคิด 3 ถึง 5 หน้า → เดโมสด → ความปลอดภัย → กติกาเกม → (เอกสารเกม) → (ฟีดแบ็ก AI, โจทย์สด, แบทเทิล, ผลรวม) → เอาไปใช้ที่ทำงาน
- **ปุ่มเปิดทีละขั้น:** หลายสไลด์มีการ์ดหรือข้อความที่ขึ้นทีละขั้น กดไปข้างหน้าเพื่อเปิดทีละอัน ใช้จังหวะนี้ถามห้อง
- **เกม Game Hub:** เปิดจากแผงผู้บรรยาย เลือกเกมของสัปดาห์ ตอบทีละข้อ เฉลย แล้วไปข้อถัดไป ค้างสไลด์เอกสารไว้ที่จอระหว่างตอบ (สัปดาห์ 4 และ 8)
- **โจทย์สด (Prompt Battle):** จากสไลด์ Live Prompt Challenge ใช้ **Open case** เพื่อสุ่มเคส หรือข้ามไปใช้โจทย์ของแผน แล้วเริ่มรับพรอมป์จากแผงผู้บรรยาย ผู้เล่นส่งได้ 3 ครั้ง ปิดรับ เริ่มแบทเทิล ทุกคนโหวต แล้วดูผลที่สไลด์ผลรวม
- **ฟีดแบ็กจาก AI:** เป็นคำแนะนำส่วนตัวต่อคน ไม่มีผลกับคะแนนหรืออันดับ บอกห้องเสมอ

## ถ้าเกิดเหตุไม่คาดคิด

| เหตุการณ์ | ทำอย่างไร |
|---|---|
| AI ตอบช้าหรือล่มตอนเดโม | ใช้ภาพหน้าจอหรือผลลัพธ์ที่บันทึกไว้ล่วงหน้า พูดว่า "นี่คือสิ่งที่เกิดเมื่อวาน" แล้วเล่าต่อ |
| ปุ่มฟีดแบ็ก AI ขึ้นข้อความผิดพลาด | บอกห้องให้ใช้เช็กลิสต์ 5 ข้อตัวเอง เกมและโหวตยังเล่นต่อได้ |
| มีคนเข้าห้องไม่ได้ | ให้ดูกับเพื่อนข้าง ๆ หรือสแกน QR ใหม่ รหัสห้องอยู่บนสไลด์เกม |
| เวลาเกิน | ข้ามสไลด์แนวคิดสุดท้าย หรือย่อแบทเทิลเหลือรอบเดียว อย่าข้ามความปลอดภัยและเอาไปใช้ที่ทำงาน |
| มีคนอยากใช้ข้อมูลจริง | ขอบคุณ แล้วให้แต่งข้อมูลสมมติแทน เรื่องนี้ย้ำได้ทุกสัปดาห์ |
