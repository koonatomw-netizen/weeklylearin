# Skills สำหรับงาน 4Seas

ตรวจสอบเมื่อ 26 ตุลาคม 2026 — ติดตั้ง Frontend Design และ Frontend Slides แล้วตามคำยืนยันของผู้ใช้

## พร้อมใช้ในแชทนี้

| Skill | เหมาะกับงาน |
|---|---|
| Presentations | สร้างและแก้ PowerPoint/Google Slides สำหรับรายงานและการสอน |
| Sites | พัฒนาเว็บและตรวจการใช้งาน; งานนี้ใช้แบบ local และเตรียม Cloudflare |
| Google Slides | แก้และต่อยอดสไลด์จาก Google Slides ที่มีอยู่ |
| Imagegen | สร้างภาพประกอบสำหรับบทเรียน |

## ติดตั้งเพิ่มได้

1. **Frontend Design — Anthropic (ติดตั้งแล้ว)**: แนวทางเลือกสี ตัวอักษร องค์ประกอบ และเอกลักษณ์เว็บ เหมาะกับเว็บสอนสด
   Source: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md
2. **Slidev — Slidev project**: ความรู้เรื่องสไลด์เว็บ Layout, animation, presenter mode และ export เหมาะเมื่อเลือกใช้ Slidev; ไม่จำเป็นต้องเปลี่ยนระบบ Native Web Slides ที่กำลังทำเพื่อใช้ Skill นี้
   Source: https://github.com/slidevjs/slidev/blob/main/skills/slidev/README.md
3. **PPTX — Anthropic**: สร้าง อ่าน และแก้ไฟล์ PowerPoint; มีความสามารถทับซ้อนกับ Presentations ที่พร้อมใช้อยู่แล้ว
   Source: https://github.com/anthropics/skills/blob/main/skills/pptx/SKILL.md
4. **Cloudflare Deploy — OpenAI**: ช่วยวางขั้นตอน Workers/Pages และบริการที่เกี่ยวข้อง เหมาะตอนนำเว็บขึ้นใช้งานจริง
   Source: https://github.com/openai/skills/blob/main/skills/.curated/cloudflare-deploy/SKILL.md
5. **Frontend Slides — zarazhangrui (ติดตั้งแล้ว)**: สร้างสไลด์ HTML และแปลง PowerPoint เป็นเว็บ เหมาะกับงานสไลด์บนจอฉาย; มีข้อกำหนด canvas 16:9 จึงต้องแยกจากส่วนกิจกรรมมือถือของแอปนี้
   Source: https://github.com/zarazhangrui/frontend-slides/blob/main/SKILL.md

## ข้อเสนอ

ใช้ Presentations สำหรับสไลด์รายงานประจำสัปดาห์ และ Sites ร่วมกับ Frontend Design สำหรับเว็บนี้ ส่วน Frontend Slides เก็บไว้สำหรับสไลด์ HTML แบบแยกไฟล์ และ Cloudflare Deploy เพิ่มได้เมื่อเข้าสู่ขั้น deployment

Skills เป็นคำแนะนำให้ตัวช่วยทำงาน ส่วนบัญชี API และฟังก์ชันห้องสดต้องตั้งค่าและพัฒนาแยกกัน
