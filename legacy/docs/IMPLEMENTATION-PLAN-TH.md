## ลำดับพัฒนา

1. วางโครงเว็บ ข้อมูลบทเรียน และฐานข้อมูล
2. ทำห้องสดและสิทธิ์ควบคุมห้อง สไลด์ต้องเปลี่ยนพร้อมกันหลายเครื่อง
3. ทำ Week 01 และหน้าจอผู้เรียนที่พิมพ์บนมือถือสะดวก
4. ทำเครื่องมือแก้สไลด์ ฉบับร่าง และเวอร์ชันพร้อมสอน ห้องที่เปิดอยู่ยึดเวอร์ชันเดิม
5. ทำคะแนนจำลอง ตัวเชื่อม API ฝั่งเซิร์ฟเวอร์ ผลรายบุคคล อันดับ และ CSV
6. ตรวจการสร้างห้อง การเข้าร่วม การส่งซ้ำ สิทธิ์ผู้สอน และการซ่อนข้อมูลก่อนเปิดผล
7. ส่งมอบรุ่นทดลองในโฟลเดอร์ที่กำหนด พร้อมคำแนะนำเปิดใช้งานและรายการที่ยังต้องทำ
8. เมื่อมีบัญชี Cloudflare และ API key จึงตั้งค่าบัญชี ทดสอบ AI จริง และนำขึ้นเว็บ

## การตรวจรับ

- ผู้เรียนควบคุมสไลด์หรือเปิดผลเองไม่ได้
- หน้าฉายไม่มีโน้ตส่วนตัวหรือกุญแจผู้สอน
- ผู้เรียนเห็นเฉพาะคำตอบและคำแนะนำของตัวเองก่อนเปิดอันดับ
- การส่งซ้ำไม่สร้างคำตอบหรือค่าเรียก AI ซ้ำ
- การแก้ร่างไม่เปลี่ยนคลาสที่กำลังสอน
- อันดับและคะแนนรวมคำนวณจากข้อมูลที่บันทึกจริง
- การขาด API key หรือบริการ AI ล้มเหลวต้องมีข้อความอธิบาย ไม่ปลอมเป็นคะแนน AI สำเร็จ
- ตรวจหน้าใหญ่และมือถือ และทดลองเชื่อมหลายคนก่อนนำไปสอนจริง

## แยกงานที่ยังต้องอาศัยบัญชีภายนอก

การมีไฟล์ตั้งค่า Cloudflare และตัวเชื่อม API ยังไม่ถือว่า deployment หรือ AI จริงผ่านการทดสอบ ต้องตรวจโดยใช้บัญชีและ key ที่ผู้ใช้ตั้งค่าภายหลัง และบันทึกผลตรวจจริงในเอกสารส่งมอบ
