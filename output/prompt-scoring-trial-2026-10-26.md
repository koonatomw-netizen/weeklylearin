# ผลทดลอง Prompt อ่อน–กลาง–ดี

ตรวจซ้ำเพื่อหาสาเหตุหนึ่งครั้ง พบ HTTP 404 จากผู้ให้บริการโมเดล ส่วนการตรวจสอบ API key แบบไม่สร้างข้อความตอบ HTTP 200 และแสดงโควตาฟรีเหลือ 50 ครั้ง ณ เวลาตรวจ จึงไม่ใช่กรณี API key ไม่ถูกต้องหรือโควตารายวันหมดในตอนนั้น

## โมเดลฟรีสำรองที่ลอง

- `liquid/lfm-2.5-2.6b:free`: ทั้งสามระดับยังไม่ได้ผลคะแนนที่สมบูรณ์ การตรวจสาเหตุเพิ่มเติมพบ HTTP 429 และข้อความจากผู้ให้บริการว่า shared free pool ถูกจำกัดชั่วคราว
- `xingchen-agi/xing4.0-29b-a4b:free`: ทั้งสามระดับยังไม่ได้ผลคะแนนที่สมบูรณ์ รอบกลางใช้เวลาประมาณ 18.4 วินาทีแล้วผลตอบกลับไม่จบสมบูรณ์

ไม่มีการสลับไปใช้โมเดลเสียเงินหรือแก้ค่าที่ผู้ใช้เก็บไว้ใน `.dev.vars` คะแนนที่ล้มเหลวไม่ได้ถูกแทนด้วยคะแนนจำลอง

## Prompt ที่ใช้

### อ่อน

ช่วยเขียนข้อความเชิญลูกค้ามางานให้หน่อย เอาให้น่าอ่าน

### กลาง

4Seas Nimman กำลังจัดงานขอบคุณแขก ช่วยร่างข้อความเชิญแขกเก่าทาง LINE เป็นภาษาไทย โทนสุภาพและเป็นกันเอง ขอข้อความสั้นอ่านง่าย

### ดี

บริบท: 4Seas Nimman กำลังวางแผนงานขอบคุณแขก เป็นสถานการณ์สมมติและยังไม่มีวัน เวลา ราคา หรือข้อเสนอที่ยืนยัน เป้าหมาย: ช่วยร่างข้อความเชิญร่วมงานสำหรับส่งทาง LINE ผู้อ่าน: แขกเก่าของโรงแรม ใช้น้ำเสียงอบอุ่น สุภาพ เข้าใจง่าย ข้อกำหนด: ใช้เฉพาะข้อมูลที่ให้ ห้ามแต่งวัน เวลา ราคา หรือโปรโมชัน หากข้อมูลจำเป็นยังขาดให้ถามก่อนเขียนฉบับพร้อมส่ง รูปแบบ: แยกส่วนคำถามที่ต้องยืนยันไม่เกิน 3 ข้อ กับร่างข้อความไม่เกิน 5 บรรทัดภาษาไทย ตามด้วยฉบับภาษาอังกฤษที่มีความหมายตรงกัน โดยใช้ช่องว่าง [รอยืนยัน] สำหรับข้อมูลที่ยังไม่มี

## ข้อสรุป

ยังไม่มีคะแนนจริงที่นำมาเปรียบเทียบได้ การทดลองนี้ยืนยันได้ว่าตัวเชื่อมส่งคำขอจริงและไม่เปลี่ยนข้อผิดพลาดเป็นคะแนนปลอม แต่ยังไม่ยืนยันคุณภาพการให้คะแนนของโมเดลฟรีหรือความพร้อมใช้สอนสด ควรทดลองใหม่เมื่อผู้ให้บริการพร้อมก่อนวันสอน
