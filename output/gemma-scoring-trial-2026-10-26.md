- ใช้โมเดลตาม `.dev.vars` ของผู้ใช้: `google/gemma-4-31b-it:free`

- ไม่เปลี่ยน API key ไม่เปลี่ยนโมเดล และไม่มีการใช้โมเดลเสียเงินสำรอง

## ปัญหาที่พบและแก้แล้ว

การเรียกครั้งแรกทั้ง 3 ระดับตอบ HTTP 404: ไม่มี endpoint รองรับพารามิเตอร์ที่ขอ เนื่องจากเว็บใช้ strict JSON Schema

แก้ตัวเชื่อมเฉพาะ Gemma 4 รุ่นฟรี 31B และ 26B ให้ขอ JSON object พร้อมอธิบาย schema ในคำสั่ง และตรวจคะแนนแต่ละด้านกับขอบเขตเดิมในระบบ เพิ่มขนาดคำตอบเป็น 1600 tokens และปิด reasoning สำหรับสองรุ่นนี้ รุ่นอื่นยังใช้วิธีเดิม ไม่มีการแปลงข้อผิดพลาดเป็นคะแนนจำลอง

ตรวจ build และ Worker typecheck ผ่าน รวมทั้งชุดทดสอบอัตโนมัติ 30 กรณี

## ผลเรียกจริงหลังแก้

| ระดับ | เวลา | สถานะ | คะแนน |
|---|---:|---|---|
| อ่อน | 0.8 วินาที | HTTP 429 ผู้ให้บริการจำกัดคำขอชั่วคราว | ไม่มี |
| กลาง | 0.4 วินาที | HTTP 429 ผู้ให้บริการจำกัดคำขอชั่วคราว | ไม่มี |
| ดี | 0.4 วินาที | HTTP 429 ผู้ให้บริการจำกัดคำขอชั่วคราว | ไม่มี |

ผู้ให้บริการ Google AI Studio แจ้งว่ารุ่นฟรีถูกจำกัดคำขอฝั่ง upstream ชั่วคราว จึงยังไม่สามารถสรุปคุณภาพคะแนนหรือความเร็วในการสร้างคำตอบได้ เวลาในตารางคือเวลาที่ได้รับข้อผิดพลาด ไม่ใช่เวลาประเมินสำเร็จ

ให้ปิดแล้วเปิดเว็บใหม่เพื่อโหลดตัวเชื่อมที่แก้แล้ว ก่อนทดลองอีกครั้งเมื่อผู้ให้บริการพร้อม
